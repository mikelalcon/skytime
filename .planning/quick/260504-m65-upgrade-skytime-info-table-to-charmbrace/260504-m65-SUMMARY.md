# Quick 260504-m65: Upgrade skytime info Table to Lipgloss Summary

**One-liner:** `skytime info` table renderer migrated from `text/tabwriter` to `charm.land/lipgloss/v2/table` (rounded Unicode-box-drawing border + bold header via StyleFunc on HeaderRow), behavioral contract preserved verbatim.

## What Changed

### Visual upgrade (the user-facing change)

Before: plain whitespace-aligned columns rendered via `text/tabwriter` (no borders, no header emphasis).

After: bordered Unicode-box-drawing table with rounded corners (`╭─╮ │ │ ╰─╯`), vertical separators between columns, bold header row (auto-suppressed on non-TTY).

### Code surface

- **pkg/cli/info.go**: replaced `text/tabwriter.NewWriter` chain with `lipgloss/v2/table.Table` builder. New imports: `lipgloss "charm.land/lipgloss/v2"` (aliased) + `charm.land/lipgloss/v2/table`. `text/tabwriter` removed. `formatInputs`, `emDash` const, and `newInfoCommand` left untouched.
- **pkg/cli/info_test.go**: rewrote `TestInfoCmd_EmptyDescription_AndEmptyInputs_RenderEmDash` row finder. Old approach used line-anchored regex `(?m)^bare\b.*$`, which fails against lipgloss output because every row begins with the left-border rune `│`, not the cell content. New approach splits on `\n` and scans for the line containing `bare`, then asserts em-dash count via `strings.Count`. Imports updated: added `"strings"`. Other 5 TestInfoCmd_* tests passed unchanged through the migration.
- **tests/firewall_cli_test.go**: appended `"charm.land/lipgloss/v2"` to the `forbidden` slice in `TestNoCobraImportsOutsideAllowList`. The walker's existing `ip == fb || strings.HasPrefix(ip, fb+"/")` predicate covers the `/table` sub-package automatically. Doc comment updated to mention lipgloss alongside cobra/pflag/charm-log.
- **go.mod**: `charm.land/lipgloss/v2 v2.0.1` promoted from indirect to direct require (forced by the new import in pkg/cli/info.go).
- **go.sum**: `go mod tidy` picked up two new transitives (`charmbracelet/x/exp/golden`, `aymanbagabas/go-udiff`) from lipgloss's full dep tree — these were previously absent because lipgloss was indirect-only.

(The `[1m...[m` markers are SGR Bold ANSI escapes around header cells — rendered as bold by any terminal, ignored visually by `cat`. Box-drawing characters preserved byte-for-byte.)

### `go run ./cmd/skytime info examples/skeleton/expression_if.star | cat` (piped — box-drawing preservation check)

Output is byte-identical to the above. Box-drawing runes (`╭ ─ ╮ │ ┬ ┼ ┤ ├ ┴ ╯ ╰`) are Unicode glyphs, not ANSI control sequences — `cat` forwards them through, the consuming terminal renders them as the table border. Verified via `od -c`:

```
0000000    ╭  **  **   ─  **  **   ─  **  **   ─  **  **   ─  **  **   ─
...
0000060    ─  **  **   ─  **  **   ─  **  **   ─  **  **   ─  **  **   ┬
```

The `╭` and `┬` runes are present in the byte stream — locked decision #6 ("box-drawing characters preserved when piped") satisfied.
