## Decisions Made

- **Source-order operation listing.** Operations documented in the order they appear in `pkg/extension/builtin/http/http.go::Operations` (get → head → post → put → delete), NOT alphabetical. This matches the locked plan structure and reflects how a flow author reads the source when verifying behavior.
- **Concrete credential routing table added.** Beyond the plan's mandate to document JIT resolution, added a Bearer/Basic/APIKey routing table from `applyCredential` because flow authors need to know which `Authorization` header shape lands on the wire when they pick a credential kind.
- **Inline mixed-idempotency reject + valid-split example.** The D4-14 section shows both the REJECTED block-batch and the OK two-step rewrite, anticipating the most common consultant footgun.
- **Per-step retry override examples added.** Showed both `retry_policy(max_attempts=1)` (suppress 5xx retries on destructive ops) and `max_attempts=10` (amplify retries for transient flakes) — makes the 4xx/5xx classification actionable.
- **`block_fn` runtime-built batch example included** in the block-batch pattern section since the recently-shipped Phase 04.1 corpus uses this shape.
