## Decisions Made

- **Flow-name alignment with shipped fixtures:** the plan's `<interfaces>` block referenced flow names `check_repo` and `batch_repos`, but the actual `.star` fixtures declare `simple_check` and `parallel_fanout`. README uses the shipped names so all run commands work verbatim against the corpus.

- **Cross-link to expectedErrFlows machinery:** when reading `tests/differential_test.go`, surfaced that contributors adding fail()-emitting fixtures need to register the flow name in the package-level `expectedErrFlows` map. Added this to the "Adding a New Example" section as a practical contributor note (Phase 04.2 Plan 06 established this map).

- **Found during:** Task 1 (composing the README), confirmed by reading the three .star files in full
- **Issue:** The plan's `<interfaces>` block listed `--flow check_repo` for `simple_check.star` and `--flow batch_repos` for `parallel_fanout.star`, but the actual `flow(name=...)` declarations in the shipped fixtures are `simple_check` and `parallel_fanout` respectively.
