## Decisions Made

- **expression_if.star + check_user as the canonical example** — locked by D-05; the asymmetric expression-mode pattern (one branch binds via `result()`, the other terminates via `fail()` with `${ctx.expr}` interpolation) demonstrates the four headline DSL features in the fewest lines.
- **Approximate-output snapshots over exact bytes** — labeled output blocks "approximately like this" / "colors and ms timings vary" to insulate the tutorial against future renderer tweaks (e.g., the next quick task that touches `pkg/cli/render.go`). The exact event names (`flow_start`, `step_dispatch`, `step_complete`, `result_bound`, `flow_complete`, `flow failed`) are accurate per `pkg/cli/progress_live.go`.
- **Inline `${ctx.expr}` carve-out citation** — quoted D4.1-22 + D4.2-05 from PROJECT.md directly in the conceptual blocks so a reader who only reads the tutorial still understands the project's "no string compilation" stance and where the parser-time-only carve-out fits.
- **`./skytime` relative path over PATH install in code blocks** — keeps every command runnable without requiring the reader to mutate their `PATH`; mentioned the `mv skytime /usr/local/bin/` option once for completeness.
