## WithCredfile API edges

### Q1: How should `cli.WithCredfile` handle the `SKYTIME_CREDFILE_PATH` env var?

| Option | Description | Selected |
|--------|-------------|----------|
| Env var as fallback only | If WithCredfile("") and SKYTIME_CREDFILE_PATH is set, use the env value; explicit arg always wins. RECOMMENDED. | ✓ |
| Env var pre-empts arg | SKYTIME_CREDFILE_PATH always wins if set. | |
| No env-var lookup in pkg/cli | pkg/cli library-pure; consumers compose own env-var policy. | |

**User's choice:** Env var as fallback only.
**Notes:** Standard Unix precedence (explicit > env > default); minimal change for existing extbin users.

### Q2: How should `cli.WithCredfile` interact with also-passed `cli.WithCredentialHandler`?

| Option | Description | Selected |
|--------|-------------|----------|
| Last call wins (silent) | Standard Go option idiom; whichever option ran last sets cfg.credHandler. RECOMMENDED. | ✓ |
| Error at construction | Loud failure on conflicting config. | |
| Documented precedence | WithCredentialHandler always wins (escape hatch); WithCredfile no-op if handler installed. | |

**User's choice:** Last call wins (silent).

### Q3: What about the `--credfile` flag override hook (currently `SetCredfilePath`)?

| Option | Description | Selected |
|--------|-------------|----------|
| Keep --credfile working | Handler installed by WithCredfile implements SetCredfilePath; flag pre-empts option arg. RECOMMENDED. | |
| Remove --credfile flag | Once WithCredfile owns the path, flag is redundant. | |
| Make --credfile flag option-aware | Hybrid; flag only works with lazy handler. | |
| **Other (free text)** | "Why do we have two flags? lets consolidate" | ✓ |

**User's choice:** Free text — "Why do we have two flags? lets consolidate"
**Follow-up confirmation:** After Claude reflected back a "drop --credfile flag" interpretation, user clarified: "sounds good to have one flag and one ENV_VAR that actuates the same option."
**Locked:** Keep `--credfile` flag AND `SKYTIME_CREDFILE_PATH` env var; both feed one option's resolution chain: `--credfile` flag > env var > `WithCredfile(arg)` > built-in default. No scattered SetCredfilePath plumbing per subcommand.

### Q4: Where does `WithCredfile` live in the package layout?

| Option | Description | Selected |
|--------|-------------|----------|
| pkg/cli/options.go | Same file as other Options. RECOMMENDED. | ✓ |
| pkg/cli/credfile.go (new) | Co-locate option + lifted lazy handler. | |

**User's choice:** pkg/cli/options.go (for the option declaration; handler implementation file is a planner-level call).
