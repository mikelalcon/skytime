# Phase 07.3 Plan 04: Dashboard wire-up + manual trigger + B3/B4/M1/M2/M3 closure Summary

End-to-end UI-01..UI-04 in one plan: the embedded HTML template renders three panels (workflows, recent webhook deliveries, manual trigger form), the SSE handler streams deltas via the Plan 03 broadcaster, and the POST /api/trigger handler dispatches workflows through the Plan 01 flowlaunch seam with fresh `manual/<flow>/<32hex>` IDs. The Phase 7.3 checker blockers (B3 shutdown order, B4 XSS defense, M1 FlowNames vs Names, M2 firewall non-vacuity, M3 JSON-strict same-origin, m3 negative-flag validation) all landed in code with pinning tests.

## Constraints checked

- **B3 — shutdown order** — `grep -n 'webResult.Shutdown\|srv.Shutdown(' pkg/cli/server.go` shows `webResult.Shutdown()` at line 372 < `srv.Shutdown(drainCtx)` at line 383 (strict line-number ordering). The 50ms grace sleep sits between them. `webResult.Shutdown()` fires the broadcaster close → SSE handlers select on the subscriber channel, see it close, emit a final `event: shutdown\ndata: null\n\n` frame, flush, and return — before listener drain cancels their request contexts.
- **B4 — XSS defense** — `grep -cE '\.innerHTML|\.outerHTML|insertAdjacentHTML|eval\(' pkg/cli/server/web/dashboard.html` returns 0; `grep -c textContent pkg/cli/server/web/dashboard.html` returns 10. The inline JS builds every DOM mutation via `document.createElement` + `.textContent` + `.setAttribute` + `.append`/`.appendChild`. The trigger feedback string is built by concatenation, then assigned to `.textContent` — never `.innerHTML`.
- **M1 — FlowNames** — `grep -c 'Registry.FlowNames()' pkg/cli/server/web/handlers.go` returns 1; `grep -c 'Registry.Names(' pkg/cli/server/web/handlers.go` returns 0.
- **M2 — firewall non-vacuity** — `tests/firewall_web_stdlib_test.go::TestNoExternalHTTPTemplateInWeb` walks `pkg/cli/server/web/` AST imports, asserts the allow-list (stdlib + go.temporal.io + google.golang.org + own module), AND asserts `sawTemporalImport == true` at the end. The canary catches the regression where a future commit strips every Temporal import and silently makes the firewall vacuous.
- **M3 — JSON-strict same-origin** — `sameOriginOK` in `pkg/cli/server/web/handlers.go` returns `origin != "" && origin == h.opts.AllowedOrigin` when `Content-Type: application/json`. Empty Origin is REJECTED for JSON; lenient fallback (`origin == "" || origin == AllowedOrigin`) for non-JSON content types so curl `--data` CLI clients still work. `TestTrigger_SameOriginCheck_JSONRequiresOrigin` pins all three scenarios.
- **m3 — flag validation** — `cmd.Flags().Int64Var(&replayHistoryThreshold, "replay-history-threshold", 50, ...)` registered; RunE rejects `replayHistoryThreshold < 0` with `fmt.Errorf("--replay-history-threshold must be >= 0; got %d (use 0 for the default of 50)", ...)`. Verified end-to-end: `go run ./cmd/skytime server --replay-history-threshold=-1 ...` returns `Error: --replay-history-threshold must be >= 0; got -1 (use 0 for the default of 50)`.
- **Pitfall 8 — SSE WriteTimeout** — `http.NewResponseController(w).SetWriteDeadline(time.Time{})` called inline (single line). `TestSSE_WriteTimeoutDisabled` pins via `httptest.NewUnstartedServer` with `WriteTimeout=100ms` + 300ms sleep + Publish + frame read — connection survives.
- **Pitfall 10 — no echo on error** — trigger errors return generic strings only. `TestTrigger_BadJSON_DoesNotEchoInput` POSTs body `"secret-value-not-json"` + asserts `require.NotContains(t, body, secret)`.
- **Pitfall 7 — crypto/rand IDs** — `var buf [16]byte; rand.Read(buf[:])` → `manual/<flow>/<32hex>` per dispatch.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] stubClient nil-panic on dashboard poller boot**
- **Found during:** Task 2 (first `go test ./pkg/cli/...` after wiring `web.Mount`)
- **Issue:** `pkg/cli/server_test.go::stubClient` embeds `client.Client` but doesn't implement `ListOpenWorkflow`/`ListClosedWorkflow`. The dashboard's workflow poller calls both on the 2s cadence inside the Mount goroutine; the embedded-nil client crashes with `runtime error: invalid memory address or nil pointer dereference` on the first tick. The poller's `tick` does `logger.Warn + swallow` for transient errors (Pitfall 4), but a nil-pointer dereference panics regardless.
- **Fix:** extended stubClient with two no-op methods returning empty `ListOpenWorkflowExecutionsResponse`/`ListClosedWorkflowExecutionsResponse`. Added `go.temporal.io/api/workflowservice/v1` import.
- **Files modified:** `pkg/cli/server_test.go`
- **Commit:** 8896d0d

**2. [Rule 1 — Bug] new hookStage() calls broke the existing 7-stage drain assertion**
- **Found during:** Task 2 (running `TestServerCmd_DrainOnSIGTERM` after the first shutdown-reorder edit)
- **Issue:** Initial wiring added `hookStage("web_shutdown_started")` + `hookStage("web_shutdown_complete")` between `signal_received` and `listener_shutdown_started`. The existing `TestServerCmd_DrainOnSIGTERM` asserts the exact 7-stage sequence and failed with the new 9-stage trace.
- **Fix:** removed the new `hookStage()` calls but kept `webResult.Shutdown()` + 50ms sleep + `srv.Shutdown(drainCtx)` in place. Per the plan's stated intent ("`TestServerCmd_DrainOnSIGTERM` continues to pass — Plan 05 will EXTEND it"), the existing hook sequence stays stable; the SSE-frame-delivery assertion lives in Plan 05.
- **Files modified:** `pkg/cli/server.go`
- **Commit:** 8896d0d

**3. [Rule 3 — Blocking issue] golden file was time.Now()-dependent**
- **Found during:** Task 1 (running `TestTemplate_DashboardGolden` after the bootstrap write)
- **Issue:** `goldenData` set Workflow.Status = "running" + CloseTime = nil → `formatDuration(start, nil)` uses `time.Now()` → golden bytes changed on every run.
- **Fix:** flipped the workflow to Status = "completed" + pinned CloseTime to a fixed timestamp (start + 12s) so the rendered "Duration" cell is deterministic ("12s").
- **Files modified:** `pkg/cli/server/web/templates_test.go` + regenerated golden via `GSD_UPDATE_GOLDEN=1`.
- **Commit:** ad58eb6
