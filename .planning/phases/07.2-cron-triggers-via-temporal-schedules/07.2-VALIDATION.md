> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `go test` + `github.com/stretchr/testify` (require/assert) |
| **Config file** | none — plain `go test` |
| **Quick run command** | `go test ./pkg/extension/builtin/core/... ./pkg/extension/schedules/... ./pkg/cli/... -count=1 -race` |
| **Full suite command** | `go test ./... -count=1 -race` |
| **Estimated runtime** | ~5s quick / ~30s full (existing baseline ~20s) |

---

## Sampling Rate

- **After every task commit:** Run quick command (`./pkg/extension/builtin/core/... ./pkg/extension/schedules/... ./pkg/cli/...`)
- **After every plan wave:** Run full suite (`./...`)
- **Before `/gsd:verify-work`:** Full suite must be green AND `tests/firewall_credential_redaction_test.go` + `pkg/activity/firewall_test.go::TestNoTemporalImportsOutsideAllowList` pass with new packages added to allowlists/targetDirs.
- **Max feedback latency:** 30s
