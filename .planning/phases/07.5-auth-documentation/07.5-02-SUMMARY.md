## Decisions Made

- **`NewAPIKeyDynamicCredentials` not `Static`** — the page intro explicitly anti-patterns the Static variant as suitable only for short-running CLI invocations. Production worker code rotates, so the snippet uses the Dynamic variant with the closure re-reading the GSM secret on every RPC.
- **`secretmanager.Client` constructed once, leaked on shutdown** — production-quality code reuses the client across RPCs (per-call construction would negate the dynamic-rotation benefit). The shutdown leak is documented inline so readers know what to do in their own binaries.
- **Comment reword: avoid the literal token `TLSDisabled`** — the project firewall gate `! grep -q 'TLSDisabled' gcp.go` is meant to catch code that actually disables TLS, but it would also fire on a comment containing the word. Reworded the warning as "do NOT disable TLS via ConnectionOptions" — preserves the intent of the warning AND satisfies the gate. Same reword applied to the markdown fence body so drift-test passes.
- **`go mod tidy` picks the version, not a manual pin** — matches Plan 01's stance (each Wave 2 plan lets `go mod tidy` resolve the cloud-SDK transitive at execution time; no stale-pin risk).
