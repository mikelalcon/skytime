## Decisions Made

- **Standalone module (no `go.work`)** — D-7.5-06 discretionary call. Confirmed no `go.work` at repo root. Standalone is simpler and the snippets module has no internal callers anyway.
- **Drift-test mechanism: stdlib Go test reading both files** — D-7.5-05 discretionary call. Chose `os.ReadFile` + `regexp.MustCompile` over embedmd-style external tooling. Zero new dependencies, runs in milliseconds, fits the existing markdown-firewall-test precedent (`tests/walkthrough_dashboard_headings_test.go`).
- **Whitespace normalization via `strings.TrimSpace`** — Both fence body and file body get trimmed before byte comparison. Lets the markdown have human-friendly indentation around the fence without showing drift.
- **Initial `go.mod` minimal (Temporal SDK only)** — The plan's note about pre-listing cloud SDK requires was advisory. Pre-listing them now without corresponding imports would cause `go mod tidy` (which Wave 2 plans will run) to strip them. Cleaner to let each Wave 2 plan add its own cloud-SDK require + transitives in one atomic `go mod tidy` step.
- **Section heading slugs pre-computed in the directory table** — GitHub-flavored Markdown auto-slugifies headings with em-dashes to double-dash anchors (`gcp--workload-identity-federation--secret-manager`). Pre-computing them in the Pick-your-section table prevents Wave 2 plans from having to verify slug correctness.
