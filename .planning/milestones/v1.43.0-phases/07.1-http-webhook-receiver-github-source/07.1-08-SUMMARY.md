### TRIG-09: HMAC firewall extended cross-package

Plan 01's `TestSignature_HMACEqualNotBytesEqual` was an in-file source-grep — it asserted no literal `bytes.Equal` substring in `signature.go`. That gate is necessary but not sufficient: any new file in `pkg/extension/receiver/` could slip in a `bytes.Equal` call without triggering it.

Plan 08's `TestReceiverFirewall_HMACOnly` is the cross-package defense-in-depth: it AST-walks every `*.go` file under `pkg/extension/receiver/` (skipping `_test.go`), inspects every `*ast.CallExpr` for a `*ast.SelectorExpr` matching `bytes.Equal`, and fails with the file path + line number on any match. The error message names `crypto/hmac.Equal` as the constant-time alternative and references `pkg/extension/receiver/signature.go` as the canonical implementation.

The current state: 0 violations across all of `pkg/extension/receiver/*.go`. Plan 04b's `handler.go` (the largest file in the package, 458 lines, 3 `.Reveal()` call sites) is clean — HMAC computation goes through `validateHMAC` in `signature.go` which uses `hmac.Equal`.

### Credential-redaction firewall coverage extended

`tests/firewall_credential_redaction_test.go::targetDirs` extended from 3 entries (Phase 7's pkg/dag + pkg/extension + pkg/extension/builtin) to 5:

- Added `pkg/extension/receiver` — Plan 01-04b production files. The most sensitive new package: `handler.go` has 3 `.Reveal()` call sites for HMAC computation, all inside `credentialBytes()` and all preceded by `// SECURITY:` comments. The firewall AST-walks every fmt-family call in this package and rejects `%+v` / `%#v` in the format-string position; combined with the type-level redaction in `extension.Secret`, this makes a credential leak via printf-style formatting structurally impossible.

- Added `examples/http-github-webhook/extensions/github` — Plan 03 production files (the `github.webhook` source factory + Initialize wiring). Less sensitive than the receiver but shipped as a TriggerSource and therefore inside the credential-handling code path; gating fmt verbs here closes the last hole in the Phase 7.1 production tree.

The firewall test now scans 5 directories and reports 0 violations — full coverage of the credential-handling code paths.
