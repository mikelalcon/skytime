## Cron-string Rejection Matrix

| Input | Result |
|-------|--------|
| `"0 9 * * 1"` (5-field POSIX) | ✓ accepted |
| `"0 0 9 * * 1"` (6-field with seconds) | ✗ *dag.ParseError* (`invalid 5-field POSIX cron`) |
| `"@hourly"`, `"@daily"` (macros) | ✗ *dag.ParseError* (no `cron.Descriptor` flag — Pitfall 6) |
| `"not a cron"` (malformed) | ✗ *dag.ParseError* (robfig/cron parse failure) |
| `timezone="America/Atlantis"` (unknown IANA) | ✗ *dag.ParseError* with hint `use IANA name like "America/New_York"` |
| `overlap="yolo"` (not in allowlist) | ✗ *dag.ParseError* listing `[allow buffer_one cancel_other skip]` |
| `catchup_window="notaduration"` (malformed) | ✗ *dag.ParseError* (time.ParseDuration fails) |
| `catchup_window="-1m"` (negative) | ✗ *dag.ParseError* (`catchup_window must be non-negative`) |

## CronSource Exported Alias

`type CronSource = cronSource` in cron.go gives Plan 02's reconciler the type assertion seam:

```go
src, ok := t.Source.(*skycore.CronSource) // (*cronSource) under the hood
if !ok { /* not a cron trigger; skip */ }
// Use src.Schedule(), src.Timezone(), src.Overlap(), src.CatchupWindow()
```

The underlying struct + its fields remain unexported; only the accessor methods are visible across packages. This preserves the "no Schedule API call at parse time" invariant — Plan 02's reconciler reads the validated values back, never re-validates them.

## time/tzdata Location

Blank import lives in `core.go` (NOT `cron.go`) so that the embedded IANA zoneinfo database is pulled into any binary that registers `skycore.New()`. The line:

```go
import _ "time/tzdata" // SECURITY: embeds IANA zoneinfo so time.LoadLocation works in scratch/distroless containers (Pitfall 3, ~450KB binary cost).
```

Rationale: a binary that consumes `cron.go`'s `*cronSource` (e.g., a reconciler that round-trips Schedule envelopes) but does NOT register `core.New()` would not need the tzdata. But every binary registering `core.New()` accepts cron triggers parsed against IANA names — those binaries must resolve `time.LoadLocation("America/New_York")` at trigger-fire time (Plan 02 reconciler) AND at parse time. The blank import in core.go (entered via `core.New()`) guarantees both.
