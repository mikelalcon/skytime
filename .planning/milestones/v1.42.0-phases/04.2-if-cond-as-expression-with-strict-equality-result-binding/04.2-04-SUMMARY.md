## Accomplishments

- **walk_result.go::bindResultToState** — pure CPU walker helper that iterates `n.Keys` (the source insertion order), evaluates each per-key value lambda via `i.evalLambda`, builds a frozen `*starlark.Dict`, converts to Go via `bridge.FromStarlarkValue`, and writes via `i.state.setOutput(outputAlias, goVal)`. Emits exactly one `result_bound` slog event with `alias`, `keys` (`[]string`), and `path` attrs BEFORE the outer if_cond's deferred `step_complete{kind=if_cond}` fires. Defensive nil-captured-lambda check returns a workflow-level error (parser invariant violation surfaces as workflow failure, not panic).
- **walk_fail.go::raiseFail** — resolves `n.Message` verbatim or evaluates `n.MessageFn` (with literal-Message fallback on eval error or wrong-type return — display safety must not crash the workflow; failure semantics still raise). Returns `temporal.NewNonRetryableApplicationError` with type `"FailNode"` carrying `n.Pos` and the resolved message. Mirrors `stepDisplayLabel`'s NameFn pattern from `walk_step.go`.
- **walk_ifcond.go expression-mode dispatch** — when `n.OutputAlias != ""`, splits the chosen branch into leading body + last node; walks leading via `i.walkBody`; type-switches on last node (`*dag.Result` → `bindResultToState`; `*dag.Fail` → `raiseFail`); defensive fallthrough to procedural `walkBody` for malformed DAGs (parser validator should have rejected them; runtime fallthrough is defense-in-depth). Procedural-mode (`OutputAlias == ""`) walks the branch verbatim — every existing pkg/interpreter/walk_ifcond_test.go test stays GREEN.
- **parseSrcAsFlow test helper** — real-parser session against an in-memory .star source written to t.TempDir(). Returns the interpreter's `*ParsedFlow` with `{Flow, Lambdas: p.Lambdas()}` splice (pkg/parser doesn't export a ParsedFlow type — the splice mirrors tests/differential_test.go's worker-bootstrap convention). Helper signature locked: `func parseSrcAsFlow(t *testing.T, src, flowName string) *ParsedFlow`.
- **eventCapturingLogger** — Temporal `log.Logger` implementation with sync.Mutex-guarded record list, `snapshot()` for defensive copy, `serializeRecords()` for sorted-key stable string output, `findEventRecords()` for event-name filtering. Used by replay-determinism tests to compare byte-equal event sequences across two runs of the same fixture.
- **Replay determinism — three new tests under `-race`:**
  - `TestReplay_DictKeyOrderDeterministic` — fixture with `result(value={"c":1,"a":2,"b":3})` (intentionally non-alphabetical Keys); two runs produce byte-equal serialized event sequences AND the result_bound event's `Attrs["keys"]` is exactly `[]string{"c","a","b"}` (Pitfall 5: source insertion order, NOT alphabetical, NOT Go-map iteration).
  - `TestReplay_FailMessageDeterministic` — fixture with `fail("repo ${ctx.repo} not found")` interpolation; two runs produce byte-equal `env.GetWorkflowError().Error()` strings containing `octocat/Hello-World`.
  - `TestReplay_LeadingBodyDeterministic` — fixture with `then=[script(...), result(value={"x": ctx.m})]`; two runs produce byte-equal final state with `ctx.m == 10` (script ran first) and `ctx.r.x == 10` (result lambda read ctx.m AFTER script set it).
- **All 3 RED interpreter tests from plan 01 turn GREEN:** TestWalkIfCond_ResultBoundToCtx, TestWalkIfCond_FailRaisesNonRetryable, TestReplay_DictKeyOrderDeterministic (the latter promoted to replay_determinism_test.go with comprehensive scaffold).

## Decisions Made

- **`parseSrcAsFlow` returns the interpreter's `ParsedFlow` shape** — `pkg/parser` does not export a `ParsedFlow` type; it returns `map[string]*dag.Flow` plus accessor methods (`p.Lambdas()`, `p.FileBytes()`). The helper splices these into `&ParsedFlow{Flow: f, Lambdas: p.Lambdas()}` — mirrors the worker-bootstrap convention in `tests/differential_test.go`. The signature is locked: `func parseSrcAsFlow(t *testing.T, src, flowName string) *ParsedFlow`.
- **`eventCapturingLogger` over `slog.Handler` (Rule 1 deviation)** — initial Task 3 implementation used `slog.SetDefault` + a custom `slog.Handler`, but `workflow.GetLogger(ctx)` routes through `testsuite.SetLogger` (Temporal's `log.Logger` interface), NOT `slog.SetDefault`. The slog handler captured zero records. Switched to mirror the existing `pkg/interpreter/walk_step_namefn_test.go::captureLogger` pattern (Temporal `log.Logger`) and extended with `snapshot()`/`serializeRecords()`/`findEventRecords()` seams. Single canonical event-capture helper across the package.
- **`require.EqualValues` numeric coercion in `TestWalkIfCond_ResultBoundToCtx` (Rule 1 deviation)** — the existing Wave-0 RED stub asserted `require.Equal(int64(3), dict["magnitude"])`, but `env.GetWorkflowResult` round-trips through testsuite's JSON DataConverter, surfacing `int64` as `float64`. Switched to `require.EqualValues` per the plan's must-haves note (`accept either int64 or json.Number depending on the bridge's standard conversion`). In-memory state map (before JSON) stores `int64` — replay tests cover that directly via the `eventCapturingLogger`'s pre-JSON record snapshots.
- **`TestReplay_DictKeyOrderDeterministic` promoted to `replay_determinism_test.go`** — the Wave-0 RED stub in `walk_ifcond_expression_test.go` was a simple two-runs-equal check; plan-04 acceptance criteria mandate this test live in `replay_determinism_test.go` with the comprehensive scaffold (`eventCapturingLogger` + `serializeRecords` + Pitfall-5 substring audit + slice-equality on `Attrs["keys"]`). Old stub left a comment forwarder pointing to the new home for future readers.
- **Defensive fallthrough on non-Result/Fail terminator** — plan 03's parser-time `validateIfCondExpressionShape` rejects malformed expression-mode branches at parse time, but if the validator regresses, the runtime walker's switch falls through to procedural-mode `walkBody`. Malformed DAGs behave like procedural mode and never bind the alias — defense-in-depth that prevents runtime panic; parse-time error should have stopped them.
- **`bindResultToState` defensive nil-captured-lambda check** — plan 02's parser guarantees `n.Values[k]` is set for every `k` in `n.Keys`. A nil here means the parse-time invariant broke; surface as a workflow-level error rather than panic. Kept narrow: error includes the key name and `n.Pos` for triage.
