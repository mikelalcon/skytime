### New behaviors → test layer mapping (from RESEARCH.md)

| Behavior | Test Layer | Test Technique | Representative Failing Case |
|----------|-----------|----------------|------------------------------|
| Desugarer produces correct lambda AST | `pkg/parser` unit | Golden — synthesized lambda eval result equals manual `lambda ctx: ...` eval | `"prefix${ctx.foo}suffix"` evaluates to wrong concatenation |
| Validator catches `${ctx.typo}` at parse time | `pkg/parser` unit (extends D4-02) | Table-driven `*dag.ValidationError` with position of opening `${` | Typo passes parse; surfaces only at runtime |
| `${...}` scanner edge cases | `pkg/parser` unit | Table-driven (escape `$$`, nested braces, unterminated, empty `${}`) | `"$${literal}"` over-desugars |
| `action_fn` strict return contract | `pkg/interpreter` unit | TestWorkflowEnvironment + assert `NonRetryableErrResult` carrying lambda position | Returning a list from `action_fn` succeeds silently |
| `block_fn` strict return contract | `pkg/interpreter` unit | Same as above, list-of-ActionRef expected | Returning a single ActionRef from `block_fn` succeeds silently |
| `block_fn` parse-time idempotency classifier | `pkg/parser` unit | Table-driven over AST shapes (typed call, opaque, comprehension, conditional) | Heterogeneous batch passes parse without runtime fallback flag set |
| `block_fn` runtime idempotency fallback | `pkg/activity` unit | TestActivityEnvironment with mixed batch returned by lambda | Mixed batch dispatches without rejection |
| `block_fn` size cap (50) at runtime | `pkg/activity` unit | TestActivityEnvironment, batch of 51 ActionRefs | Oversized batch dispatches successfully |
| Live block: cursor-up + line-clear sequence | `pkg/cli` unit | In-memory writer + `forceTTY=true`; assert ANSI byte sequences | Stale lines retained; spinner doubles up |
| Live block: spinner cadence (100ms) | `pkg/cli` unit | Synthetic clock; assert frame index advances per tick | Cadence drift / pinned to first frame |
