## Marker Keys Per Builtin

Verbatim list (across the 8 builtins, populated in `pkg/parser/builtins.go`):

- **Universal** (every builtin): `summary`, `returns`, `since`, `example`
- **Optional**: `see` (comma-separated related-builtin list)
- **Per-param overrides**: `param_<name>` (type hint), `desc_<name>` (description column for the params table)

Multi-line summaries supported via repeated `// skytime:doc summary="..."` lines (joined with `\n\n` paragraph break by `joinValues`).

`fail()` is positional-only (UnpackPositionalArgs in the Go signature); its `param_message` + `desc_message` markers feed the renderer's positional-only-with-markers fallback to produce a single-row params table — the `_Positional-only signature_` sentinel does NOT appear because markers are present.

## Renderer Template Body

Single `text/template` body (`builtinsTemplate` const in `cmd/skytime-docgen/render.go`):

- **Preamble**: title + "Generated by `cmd/skytime-docgen`. Do not edit by hand" + cross-link to `../architecture.md`
- **Per-builtin section** (delimited by `---` horizontal rule):
  - `## <name>` heading
  - Summary prose (multi-line summaries joined with `\n\n` paragraph break)
  - `**Signature:** \`name(p1, p2?, p3)\`` line (optional params suffixed with `?`)
  - Either a 4-column params table (`Param | Type | Required | Description`) OR `_Positional-only signature; see Example below._` sentinel
  - `**Returns:** <returns text>` line
  - `**Example:**` block followed by a python-fenced code block
  - `**See also:** <see text>` (omitted when `see` marker absent)
  - `**Since:** <since text>` line

Empty cells in tables render as em-dash (U+2014), matching `skytime info`'s lipgloss table convention.

## Drift Test Mechanism

`tests/docgen_drift_test.go::TestDocgenDrift`:

1. `findModuleRootDocgen(t)` walks up from cwd to the first `go.mod` directory (mirrors `findModuleRootCLI` / `findModuleRootE2E` siblings).
2. Reads checked-in `docs/reference/builtins.md` into `wantBytes`.
3. Execs `go run github.com/mikelalcon/skytime/cmd/skytime-docgen --pkg <root>/pkg/parser --out <tempfile>` — captures stderr; failure → `t.Fatalf` with stderr.
4. Reads the tempfile into `got`.
5. `bytes.Equal(wantBytes, got)` → on mismatch, surfaces a 200-char diff (truncated via `truncateDocgen`) with the instruction `Run \`go generate ./pkg/parser/\` and commit the result.`.

## Idempotency Proof

`go generate ./pkg/parser/` is byte-deterministic — running twice produces identical output (verified by `cp /tmp/run1.md && go generate && diff /tmp/run1.md docs/reference/builtins.md` returning zero diff during plan execution).

The drift test passing on a fresh checkout (after `go generate`) is the standing proof: any non-determinism would surface as a CI failure.

Internal determinism guarantees:
- Walker (plan 01) preserves `newParseTimeGlobals` source-insertion order via paired `(map, []order)` return — no Go-map iteration order leakage.
- Renderer (this plan) sorts `param_*` markers in `deriveParams` + `signatureLine` via `sort.Strings`; per-Param iteration in `derive` walks `b.Params` in walker-emitted (registration) order; multi-line summaries join via `\n\n` (deterministic across runs).

## Decisions Made

- **stdlib `text/template` over third-party templating:** preserves the plan-01 stdlib-only stance for `cmd/skytime-docgen`; firewall test stays unchanged.
- **Pre-derive `[]renderedBuiltin` over template helper funcs:** template body stays declarative; the `derive()` Go function is the single point where marker semantics (joinValues, firstValue with fallback, paramType heuristic ladder) are applied — easier to test in isolation.
- **Positional-only-with-markers fallback over walker schema change:** `fail()`'s `UnpackPositionalArgs` shape returns `[]Param=[]` from plan 01's walker; rather than retrofit the walker, the renderer synthesizes rows from `sort.Strings`-ordered `param_*` markers. Plan 01's walker contract is preserved verbatim.
- **`sort.Strings` for deterministic `param_*` marker iteration:** Go map iteration is randomized; without sorting, two runs would shuffle row order and the drift test would fail intermittently. `TestRenderMarkdown_PositionalOnly_WithMarkers_Idempotent` pins this verbatim.
- **Em-dash (U+2014) sentinel for empty cells:** mirrors `skytime info`'s lipgloss table convention from `pkg/cli/info.go`.
- **`package firewall_test` for `tests/docgen_drift_test.go`:** single external-test-package convention in `tests/`. Helpers suffixed `Docgen` to avoid collision with `findModuleRootCLI` / `findModuleRootE2E`.
- **`//go:generate` directive uses the absolute module path:** `github.com/mikelalcon/skytime/cmd/skytime-docgen` works whether cwd is module root or `pkg/parser/`.
- **Checked-in `docs/reference/builtins.md` is the single source of truth:** drift test + CI gate ensure generator output stays in lock-step with source markers.
