## Decisions Made

1. **8 persistent flags documented, not 10.** The plan's `<interfaces>` "Persistent Flag Table" listed `--rootdir` and `--temporal-task-queue`, neither of which exist in `pkg/cli/flags.go::registerPersistentFlags`. The plan's frontmatter `must_haves.truths` explicitly demands "Source-of-truth fidelity: each subcommand's flags + Short description match what `skytime <cmd> --help` actually prints" — so the doc reflects the source. (See "Deviations from Plan" below for the formal Rule 1 entry.)

2. **mTLS documented as cert+key pair (with optional --server-ca), not triplet.** The plan said partial-mTLS rejection fires when "1 or 2 of 3" of the mTLS flags is set; `pkg/cli/connect.go::connectClientWithFactory` actually rejects only when one of `--client-cert` or `--client-key` is provided without the other. `--server-ca` is optional (defaults to system roots). Doc reflects the actual code. (Rule 1.)

3. **Cited the named worker constructors explicitly** (`NewCloudClient`, `NewSelfHostedClient`, `NewDevClient`) in the variant-routing prose. This satisfies the plan's `>= 2` acceptance grep and gives readers a clean back-link to Phase 3's D3-15 named-constructor design.

4. **Cross-links to docs that don't yet exist** (`builtins.md`, `architecture.md`, `getting-started.md`, `for-flow-authors/README.md`, `for-extension-developers/README.md`). These are scheduled for sibling plans 01, 02, 03, 05, 06 in this phase. The plan executes in parallel (wave 1, depends_on=[]), so this doc shipping ahead of its cross-link targets is by design — the markdown file reads coherently in isolation, and the dead links serve as TODO anchors for the other agents.

5. **Documented decision IDs inline** (D4-07, D4-09 through D4-13, D4-16, D4-18, D4-19, plus CLI-06/07 and VAL-02/03) so readers can pivot from the doc to REQUIREMENTS.md / CONTEXT.md without external indices.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Plan's "Persistent Flag Table" claimed 10 flags; pkg/cli/flags.go declares 8**

- **Found during:** Task 1 (Compose docs/reference/cli.md)
- **Issue:** The plan's `<interfaces>` block listed 10 persistent flags including `--rootdir` and `--temporal-task-queue`. `pkg/cli/flags.go::registerPersistentFlags` actually declares 8 (`--debug`, `--verbose`, `--address`, `--namespace`, `--api-key`, `--client-cert`, `--client-key`, `--server-ca`). The corresponding `bindEnvVars` table maps 6 string flags to `SKYTIME_TEMPORAL_*` env vars (the booleans `--debug` and `--verbose` have no env binding).
- **Fix:** Documented the actual 8 flags with their actual env-var names (e.g., `SKYTIME_TEMPORAL_CLIENT_CERT`, not the plan's `SKYTIME_TEMPORAL_TLS_CERT`). The plan's `must_haves.truths` explicitly required source-of-truth fidelity — this is exactly the case the rule covers.
- **Files modified:** docs/reference/cli.md (Persistent Flags section)
- **Verification:** Cross-checked every flag name and env var against `pkg/cli/flags.go` lines 14-31 (registerPersistentFlags) and 49-67 (bindEnvVars). Doc matches verbatim.
- **Committed in:** 358cd1c (Task 1 commit)

**2. [Rule 1 - Bug] Plan's mTLS "triplet (1 or 2 of 3)" framing diverges from connect.go**

- **Found during:** Task 1 (skytime run flag table + variant routing prose)
- **Issue:** The plan said partial-mTLS (1 or 2 of 3 mTLS flags) is rejected before any client construction. The actual code (`pkg/cli/connect.go::connectClientWithFactory`) only rejects when exactly one of `--client-cert` / `--client-key` is set without the other; `--server-ca` is optional and supplied to the SelfHosted constructor only when present.
- **Fix:** Documented the actual behavior — cert+key pair required, server-CA optional. Variant routing description matches the source switch order: api-key → Cloud, cert+key → Self-Hosted, only one of cert/key → error, otherwise → Dev.
- **Files modified:** docs/reference/cli.md (Persistent Flags section + skytime run Flags subsection)
- **Verification:** Re-read pkg/cli/connect.go lines 60-99; the `case` arms map to the doc's bullet points one-for-one.
- **Committed in:** 358cd1c (Task 1 commit)
