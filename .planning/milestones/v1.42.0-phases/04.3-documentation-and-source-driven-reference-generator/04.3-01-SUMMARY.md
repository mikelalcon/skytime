# Phase 04.3 Plan 01: skytime-docgen AST Walker + Marker Parser Summary

**Stdlib-only Copybara-style AST walker (`cmd/skytime-docgen`) that enumerates Skytime's 8 Starlark builtins from `pkg/parser/globals.go` and extracts per-builtin parameters via `starlark.UnpackArgs` parsing + `// skytime:doc` marker blocks — JSON-to-stdout transitional shape; renderer + markers wired in plan 02.**

## Accomplishments

- `cmd/skytime-docgen` exists as a stdlib-only sibling binary to `cmd/skytime` (NO cobra, NO charm-log, NO lipgloss; library-root firewall preserved verbatim)
- `WalkRegistry` parses `pkg/parser/globals.go` via `go/ast` over the `StringDict` `CompositeLit` in `newParseTimeGlobals`, returning the 8-name registry in source-insertion order
- `WalkBuiltins` parses `pkg/parser/builtins.go` via FuncDecl traversal, extracting Params from each builtinXxx's first `starlark.UnpackArgs` (or recognizing `UnpackPositionalArgs` as a positional-only shape with empty Params)

- Live-source smoke verified: walking `pkg/parser/{globals,builtins}.go` yields all 8 builtins (flow, step, if_cond, script, for_each_parallel, call_flow, result, fail) with 30 total `Required` params populated

## Decisions Made

- **stdlib `flag`, NOT cobra (CLAUDE.md "Claude's discretion"):** docgen runs once at `go generate` time; cobra's ~3MB of transitive deps would be wasteful for a single-command tool. Net effect: cmd/skytime-docgen does NOT need a `tests/firewall_cli_test.go` allow-list entry — `cmd/skytime-docgen` is outside `pkg/` (so the firewall doesn't enforce) AND deliberately stdlib-only (so even if it leaked to `pkg/` it would not violate). The library-root firewall test stays green verbatim.
- **Order-preserving registry via paired `(map, []string)` return:** Go map iteration is randomized; preserving `newParseTimeGlobals`' source order is necessary so plan 02's renderer reads top-to-bottom as the .go file is authored (alphabetical sort would scramble the natural grouping `flow/step/if_cond` vs. `result/fail`).
- **testdata `.go.txt` extension:** sidesteps Go's package-discovery and avoids accidental compile inclusion; tests copy to `tempdir/*.go` before `go/parser` invocation. Pattern reusable for any future fixture-driven AST work.
- **Builtin/Param JSON tags use lowercase snake_case:** JSON output is documented as transitional (plan 02 ships markdown via `text/template`) but the snake_case keys make the JSON consumer-friendly during the window and align with the plan's verification grep (`grep -c '"name":\s*"flow"'`).
- **`extractUnpackParams` stops after the first `UnpackArgs`/`UnpackPositionalArgs` per FuncDecl:** every `builtinXxx` is shaped that way verbatim; matches the canonical `pkg/parser/builtins.go` pattern. Future split (e.g. multiple `UnpackArgs` per func) would require schema changes anyway.
- **ParseMarkers warn-and-skip via `fmt.Fprintln` on `os.Stderr`:** no `io.Writer` parameter — keeps the API surface minimal; `captureStderr` test helper handles assertion paths via `os.Pipe()` + `os.Stderr` swap.
