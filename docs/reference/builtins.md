## flow

Declares a workflow — the top-level unit of orchestration.

Each .star file declares one or more flows; flow names must be unique within a parser session.

**Signature:** `flow(name, inputs?, steps, task_queue?, description?)`

| Param | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `name` | string | yes | Unique flow identifier; supports ${ctx.expr} interpolation. |
| `inputs` | dict[string,string] | no | Type-hint map (e.g. {"repo":"string"}); seeds the parse-time state schema. |
| `steps` | list[Node] | yes | Body — list of step/if_cond/script/for_each_parallel/call_flow nodes. |
| `task_queue` | string | no | Optional Temporal task queue override (D3-19); empty inherits worker default. |
| `description` | string | no | Optional free-form description shown by `skytime info`. |

**Returns:** None (registers a *dag.Flow as a parse-time side effect).

**Example:**

```python
flow(
    name = "check_user",
    inputs = {"user_id": "string"},
    steps = [
        step(action = api.fetch_user(id = "${ctx.user_id}")),
    ],
)
```

**See also:** step, script, if_cond, for_each_parallel, call_flow

**Since:** phase-01

## step

Declares a sequential workflow step that dispatches one or more extension actions.

Exactly ONE of action / block / action_fn / block_fn must be provided (D4.1-06 4-way mutual exclusion).

**Signature:** `step(action?, block?, action_fn?, block_fn?, name?, retry?, timeout?, task_queue?)`

| Param | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `action` | ActionRef | no | Single static action (mutually exclusive with block/action_fn/block_fn). |
| `block` | list[ActionRef] | no | Static batch of actions (homogeneous idempotency required, D2-05). |
| `action_fn` | lambda(ctx) -> ActionRef | no | Dynamic single-action lambda (D4.1-06); evaluated inside the workflow. |
| `block_fn` | lambda(ctx) -> list[ActionRef] | no | Dynamic batch lambda (D4.1-07); empty list short-circuits without dispatch. |
| `name` | string | no | Display name; supports ${ctx.expr} interpolation (D4.1-15). |
| `retry` | RetryPolicy | no | Optional Temporal RetryPolicy (DSL-08). |
| `timeout` | Timeout | no | Optional Temporal Timeout (DSL-08). |
| `task_queue` | string | no | Optional Temporal task queue override (D3-19); precedence: step > flow > worker. |

**Returns:** A *dag.Step node consumed by flow(steps=[...]).

**Example:**

```python
step(
    name = "Fetch ${ctx.repo}",
    action = http.get(path = "/repos/${ctx.repo}"),
)
```

**See also:** flow, if_cond, for_each_parallel

**Since:** phase-01

## if_cond

Conditional branch evaluated INSIDE the workflow (zero Temporal history events for the branch decision).

Procedural mode (no output_alias): branches contain procedural nodes; today's behavior.

Expression mode (output_alias="X"): both branches must end in result(value={...}) or fail(...); the bound value lands at ctx.X (DSL-14, D4.2-09).

**Signature:** `if_cond(cond, then, else_?, output_alias?)`

| Param | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `cond` | lambda(ctx) -> bool | yes | Predicate evaluated inside the workflow; lambda-time globals only (no time, no random, no I/O). |
| `then` | list[Node] | yes | Body executed when cond is truthy. |
| `else_` | list[Node] | no | Body executed when cond is falsy. |
| `output_alias` | string | no | When non-empty, switches to expression mode and binds branch result to ctx.<alias>. |

**Returns:** A *dag.IfCond node.

**Example:**

```python
if_cond(
    output_alias = "user",
    cond = lambda ctx: ctx.user_id != "",
    then = [result(value = {"id": ctx.user_id, "ok": True})],
    else_ = [fail("invalid user_id: '${ctx.user_id}'")],
)
```

**See also:** result, fail, script

**Since:** phase-01 (procedural); phase-04.2 (expression mode)

## script

Pure state transformation evaluated INSIDE the workflow (zero Temporal history events).

The fn lambda receives ctx and returns a dict that is bound to ctx.<output_alias> for downstream nodes.

**Signature:** `script(id, fn, output_alias)`

| Param | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `id` | string | yes | Logical identifier; supports ${ctx.expr} interpolation (D4.1-02). |
| `fn` | lambda(ctx) -> dict | yes | Pure transformation; lambda-time globals only. |
| `output_alias` | string | yes | ctx attribute that receives the returned dict for downstream consumers. |

**Returns:** A *dag.Script node.

**Example:**

```python
script(
    id = "validate_${ctx.repo}",
    fn = lambda ctx: {"valid": ctx.repo != ""},
    output_alias = "validation",
)
```

**See also:** if_cond, flow

**Since:** phase-01

## for_each_parallel

Parallel fan-out with bounded concurrency (default 10; configurable via max_concurrency).

items can be a static list literal OR a lambda producer that returns a list at workflow-execute time.

**Signature:** `for_each_parallel(items, item, steps, retry?, timeout?, max_concurrency?)`

| Param | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `items` | list | lambda(ctx) -> list | yes | Static list literal or lambda producer; lambda evaluated once inside the workflow. |
| `item` | string | yes | Per-iteration variable name added to ctx for the inner steps body. |
| `steps` | list[Node] | yes | Body executed once per item with ctx.<item> bound. |
| `retry` | RetryPolicy | no | Optional inherited Temporal RetryPolicy. |
| `timeout` | Timeout | no | Optional inherited Temporal Timeout. |
| `max_concurrency` | int | no | Concurrent worker.Go fan-out cap (D3-13); 0 = interpreter default 10. |

**Returns:** A *dag.ForEachParallel node.

**Example:**

```python
for_each_parallel(
    items = lambda ctx: ctx.repos,
    item = "repo",
    max_concurrency = 5,
    steps = [step(action = http.get(path = "/repos/${ctx.repo}"))],
)
```

**See also:** step, call_flow, flow

**Since:** phase-01

## call_flow

Invoke a sub-flow as a Temporal child workflow (isolates sub-history).

**Signature:** `call_flow(name, inputs?, child_options?)`

| Param | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `name` | string | yes | Target flow name; resolved at parse finalize against the parser session's flow map (D-16). |
| `inputs` | dict[string,any] | no | Inputs passed to the child flow; merged with the child's declared inputs. |
| `child_options` | dict[string,any] | no | Pass-through Temporal child workflow options (workflow_id, retry policy, etc.). |

**Returns:** A *dag.CallFlow node.

**Example:**

```python
call_flow(
    name = "audit_repo",
    inputs = {"repo": ctx.repo},
    child_options = {"workflow_id": "audit-${ctx.repo}"},
)
```

**See also:** flow, step

**Since:** phase-01

## result

Branch terminator that binds a typed dict-literal value to ctx.<output_alias> in the enclosing if_cond expression-mode.

Only legal as the LAST node of an expression-mode if_cond branch (i.e., if_cond(output_alias="X", ...)).

Each value is captured as a per-key parse-time lambda, so ctx-references inside the dict are evaluated inside the workflow at branch-execute time.

**Signature:** `result(value)`

| Param | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `value` | dict (string-literal keys) | yes | Dict-literal at the call site; keys must be string literals; values are captured per-key as parse-time lambdas. |

**Returns:** A *dag.Result node (LEAF — no body, no children).

**Example:**

```python
if_cond(
    output_alias = "classification",
    cond = lambda ctx: ctx.size_bytes > 1000000,
    then = [result(value = {"tier": "large", "label": "needs sharding"})],
    else_ = [result(value = {"tier": "small", "label": "single host fine"})],
)
```

**See also:** if_cond, fail

**Since:** phase-04.2

## fail

Top-level builtin that emits a failure node — runtime raises a NonRetryableApplicationError at the .star callsite.

Top-level fail() (parse-time builtin) is distinct from lambda-time fail() (starlark.Universe builtin); they share the name across two predeclared environments (D4.2-05).

Supports ${ctx.expr} interpolation in the message (D4.1-01).

**Signature:** `fail(message)`

| Param | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `message` | string | yes | Single positional argument; runtime renders the message at the .star callsite, with ${ctx.expr} interpolation evaluated inside the workflow. |

**Returns:** A *dag.Fail node.

**Example:**

```python
if_cond(
    cond = lambda ctx: ctx.user_id != "",
    then = [step(action = api.fetch_user(id = ctx.user_id))],
    else_ = [fail("user_id is required")],
)
```

**See also:** result, if_cond

**Since:** phase-04.2
